# Sourced brand context

Ask the host for the current project's brand records and decision history. Use `buildBrandContextSnapshot` to retain source and approval status for each field, then pin the snapshot in the run. `resolveBrandQuestion` can answer a factual question only from a current approved field; route missing, draft, contradicted or superseded information to research or the actual decision owner. Preserve an existing approved name, palette and positioning unless this task explicitly authorizes reconsideration. The Pack supplies this resolver; the host must provide memory access and trusted decision references.

Capture brand name/status, category, audience language, alternatives, positioning, personality, values, current assets and rights as fields with exact source references. Mark every unfilled field unknown rather than completing it from intuition. This adapts Cofoundy's reusable brand context while using Core's project identity, versioned artifacts and authority model instead of a second independent `brand.yaml` authority.
