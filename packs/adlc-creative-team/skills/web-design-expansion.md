# Concept to full web design

Require an exact selected concept version. Record its direction contract: traits to preserve and details that were illustrative only. Map all required sections, content, desktop and mobile layouts, and relevant states; long pages need full-page coverage. Preserve the selected concept's central composition and visual language. Treat internal HTML used to render accurate design images as a design source, not a runnable product. Store exact copy separately from image text.

## Procedure and completion

1. Inventory pages, real content, assets and intended user actions. For each section state its purpose and why it belongs in that order; do not add invented proof or filler sections.
2. Map selected direction traits to existing tokens and reusable components. Specify typography, spacing, image crops, widths and behavior between desktop and narrow layouts.
3. Define navigation and link destinations, form labels and errors, focus states, content overflow and long/translated text treatment. Preserve existing behavior on a scoped redesign.
4. Render the complete page at agreed viewports through the host. Check clipping, loading fonts/assets, hierarchy, reading order and continuity with the selected concept. Behavioral claims require exercised controls, not screenshots.

Deliver versioned layouts, exact content, asset/license inventory, state notes and evidence coverage. Missing rendering prevents claiming visual verification; missing backend integration must remain explicit.
