# Brand guidelines

Build `brand-guidelines` from the accepted brand baseline and adopted asset versions. Include logo lockups, clear space, minimum sizes, approved backgrounds, color roles, typography and font rights, imagery, voice, messaging, examples and misuse. Link each rule to the decision or asset that authorizes it. Provide a human-readable guide and machine-readable asset/token index from the same pinned versions.

Review the document against actual files and touchpoints. If the source contains only a draft kit, label the guide a candidate. A guide consolidates accepted decisions; it cannot silently change them or grant usage rights.
