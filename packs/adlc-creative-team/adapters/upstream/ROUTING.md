# Creative method routing

This legacy directory contains documentation only, not an upstream runtime adapter. The operational instructions are fully embedded in Pack-owned Skills:

- Intake, research, concept, SaaS, system and handoff Skills contain the scoped design process informed by designer-skills.
- `visual-direction-adapter` resolves exploration and surface modes using Creative's own direction contract. Taste's opinions remain optional, below approved requirements and brand.
- `design-assurance` separates rendered, behavioral and source evidence, informed by Impeccable's critique and technical-audit distinction.
- `hallmark-design-review` adds material-led, product-specific page review. It is assigned to product direction, implementation and independent QA roles, not an automatic redesign step.

No routing step reads, resolves or downloads external sources. Optional attribution lives in `methodReferences`; optional executable tools belong to the harness under explicit host authorization. Tool results cannot grant approval authority or replace exact artifact/version checks.
