# Logo concept design

Run `logo-concept-design` from a pinned brand baseline and a bounded `new`, `refresh` or `keep` scope. Develop a broad cheap longlist, choose three genuinely different mark ideas, construct editable SVG candidates and render them at real 16/32 px sizes and in one colour and reverse. Preserve existing equity when refreshing. Treat the logo as an identifier; assess category distinction, legibility and brand fit separately.

Use the licensed tools under `adapters/brand-tools/logo-design`: `concept_sheet.py` for comparison, `svg_audit.py --json` for structural findings, `preview_sheet.py` for context tests, and `render_png.py` for visible inspection. The audit command can exit zero while reporting `FAIL`; parse its findings and record blocking issues. Do not include the upstream trademark reference library in deliverables or trace a reference mark. File validity, visual quality and brand fit are independent review results. A reviewed concept set is ready for selection; it is not an adopted logo.
