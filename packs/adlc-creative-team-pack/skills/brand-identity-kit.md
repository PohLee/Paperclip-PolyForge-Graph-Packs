# Brand identity kit

Start `brand-identity-kit` only with a pinned selected logo candidate and approved baseline. Capture the actual selector and any verified delegation; never call a Head of Design choice “user approval.” Treat logo, typography and palette as one visual mechanism. For each component, honor its `new`, `refresh`, `keep` or `none` scope. Compare a small set of coherent alternatives against the same brand brief, then refine the selected system.

Run SVG audit and real render inspection. Use `auditPalette` on actual foreground/background usages; record contrast gates separately from aesthetic judgements. This Pack's identity production scope is English only: check the required English glyphs and font usage rights with real font evidence. Do not import the upstream Turkish localization path or claim non-English coverage. Export editable SVG masters and variants with the licensed `export_variants.py`; PNG export requires an installed renderer. Supply semantic color roles and developer tokens with exact values. Leave ICC/CMYK/Pantone fields unknown until the printer supplies production conditions. The final kit is a reviewed candidate for owner adoption, not automatically a brand baseline.
