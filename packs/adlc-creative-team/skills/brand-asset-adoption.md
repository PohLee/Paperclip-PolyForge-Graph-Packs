# Brand asset adoption

Start `brand-asset-adoption` with exact references to the current baseline, reviewed identity kit and accepted independent review. Show the owner the actual rendered assets, checks, unresolved production dependencies and delta from the previous baseline. Record the real decision maker and one of `adopt`, `changes-requested` or `decline`; a Creative Director stage recommendation does not substitute for this decision.

Only `adopt` can publish a new brand baseline. The published artifact pins the previous baseline, kit, review and exact Core decision. Downstream guidelines, campaign work and packaging read the new baseline version; past assets remain traceable. The host must separately handle external publication and file distribution.
